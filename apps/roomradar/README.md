# Product Folder

This folder contains product-facing material for turning the current automation into a real software product.

## Files

- `strategy.md`
  Product positioning, MVP, monetization, risks, and roadmap.

- `demo/index.html`
  Static clickable-style demo for presentation and discussion.

## How To Open The Demo

Open `product/demo/index.html` directly in a browser.

## Demo Goal

Show that the product is more than scraping:

- search profile setup
- accepted vs rejected listing triage
- transparent rejection reasons
- approval-driven outreach
- monetization path
